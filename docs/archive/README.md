# ReguLens Documentation

This directory contains all product and platform documentation for ReguLens.

## Directory Structure

### `/features`
Functional feature documentation, requirements, and feature specifications. Document user stories, acceptance criteria, and feature roadmaps here.

### `/system-design`
System architecture, technical design documents, and design proposals. Include data flow diagrams, component interactions, and technical specifications.

### `/wireframes`
Low-fidelity wireframes and user flow diagrams. Early-stage visual concepts and navigation structures.

### `/ui-mockups`
High-fidelity UI mockups, design assets, and visual specifications. Finalized design work ready for implementation.

### `/architecture`
Architectural decision records (ADRs), infrastructure diagrams, and technology stack documentation.

### `/api-specs`
API documentation, endpoint specifications, request/response schemas, and integration guides.

### `/user-research`
User research findings, personas, user journey maps, and usability testing results.

### `/decisions`
Key product and technical decisions, trade-offs, and rationale. Use this for decision logs and retrospectives.

## Document Naming Conventions

- Use lowercase with hyphens: `feature-name.md`
- Include dates for versioned docs: `2026-04-17-design-proposal.md`
- Use descriptive names that indicate content at a glance
