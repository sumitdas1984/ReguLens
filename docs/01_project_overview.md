# Project Overview

ReguLens monitors IRS regulatory updates and alerts tax professionals when clients are affected.

## Problem

Tax professionals miss critical updates because:
- IRS publishes new guidance daily
- Manually tracking is time-consuming
- Missing updates means missed opportunities or compliance risks

## Solution

1. **Scrape** — Daily monitoring of IRS Newsroom and IRB
2. **Match** — AI links regulations to client profiles
3. **Alert** — Email digest with client-specific impact

## Approach

Foundation-first: solve data acquisition before AI.
